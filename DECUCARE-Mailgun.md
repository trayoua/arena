# Mailgun за DECUCARE — кратки стъпки

Цел: сайтът да изпраща две служебни писма при всяка заявка:
1. до собственика — детайли на поръчката/въпроса;
2. до клиента — приятно потвърждение, че заявката е приета.

Поръчката се записва в базата **преди** имейлите. Ако имейл пропадне, заявката остава в администрацията и може да се изпрати отново.

## Какво трябва да подготвите

- Mailgun акаунт.
- Домейн за изпращане на имейли, който контролирате. Това може да е `shopzon.eu`, ако решите, но **не е нужно сайтът да се мести** от `https://decucare-arena.vercel.app`.
- Достъп до DNS настройките на този домейн.
- Mailgun API ключ.
- Регион на Mailgun акаунта: препоръчително EU.
- Видим подател, напр. `DECUCARE <porachki@mg.example.com>` (заместете с вашия домейн).

## Стъпки

1. Създайте акаунт в Mailgun.
2. Добавете домейн за изпращане, напр. `mg.example.com` (препоръчително е поддомейн, за да не пречи на евентуална поща на главния домейн).
3. Mailgun ще покаже DNS записи (TXT за SPF/DKIM, понякога MX/CNAME). Добавете ги при доставчика на домейна.
4. Изчакайте DNS проверка и натиснете Verify/Check в Mailgun, докато домейнът стане активен.
5. Вземете API ключ от настройките на Mailgun. Няма да го показвам в чата; ще го запазя като защитена променлива във Vercel.
6. Изберете подател. Пример: `DECUCARE <porachki@mg.example.com>`.
7. Кажете ми:
   - домейн за изпращане;
   - API ключ;
   - регион (EU/US);
   - видим подател;
   - имейл за тест до клиента (може временен ваш имейл).

## Какво ще направя аз

- Ще добавя настройките като защитени променливи във Vercel.
- Ще публикувам нова версия.
- Ще направя тестова поръчка.
- Ще проверя, че заявката е записана.
- Ще проверя, че сте получили известие на посочения от вас имейл.
- Ще проверя, че тестовият клиент е получил потвърждение.
- Ще почистя тестовите данни.

## Важно

- Не използвайте личната си парола за Mailgun API ключ.
- Не изпращайте API ключ в публичен сайт/екранна снимка.
- Домейнът трябва да е потвърден, иначе реални клиентски имейли може да не се доставят.
- Sandbox домейн на Mailgun става само за ограничени тестове, не за реални продажби.
